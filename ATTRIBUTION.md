# Attribution and licensing status

KubeCIS Native is an independent implementation written in Go with Kubernetes client-go and other dependencies recorded in `go.mod` / `go.sum`. No Aqua Security kube-bench source or benchmark configuration corpus is packaged or executed. The published upstream dependency licenses remain the responsibility of the project maintainer to verify and attribute in release distribution.

Historical profile identifiers containing `cis-` are retained for JSON and existing profile compatibility. These limited/provisional files are not represented as complete CIS benchmark reproductions or official CIS certification.

**Release blocker:** The original repository supplied no root KubeCIS project license. No license is invented in this release candidate. The code owner must explicitly choose and add the project license before public publication.
